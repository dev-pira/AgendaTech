# 📊 Apresentações do Evento AgendaTech

Esta pasta contém as apresentações realizadas durante o evento AgendaTech de 15 de agosto de 2026.

## 🎯 Comunidades Participantes

As apresentações seguiram a seguinte ordem:

1. **DEVPIRA** - Comunidade de Piracicaba
2. **DevLimeira** - Comunidade de Limeira
3. **DevRioClaro** - Comunidade de Rio Claro
4. **DevItape** - Comunidade de Itapetininga

## 📁 Organização

Os arquivos das apresentações devem ser organizados nesta pasta, preferencialmente identificados por comunidade.

Exemplo de nomenclatura sugerida:
- `01_DEVPIRA_apresentacao.pdf`
- `02_DevLimeira_apresentacao.pdf`
- `03_DevRioClaro_apresentacao.pdf`
- `04_DevItape_apresentacao.pdf`

## 📝 Observações

- Formatos aceitos: PDF, PPTX, KEY, ou outros formatos de apresentação
- Mantenha os arquivos organizados por ordem de apresentação
- Inclua materiais complementares se houver
